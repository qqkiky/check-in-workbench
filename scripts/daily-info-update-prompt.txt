国内资讯手动更新回退说明。

日常更新已由 `.github/workflows/daily-info-update.yml` 在每天北京时间 08:00 自动执行；
需要人工补跑时，优先在 GitHub Actions 页面触发 `workflow_dispatch`，无需读取本机令牌。

本地手动回退流程（项目目录：D:\WorkBuddyProjects\打卡工作台）：

1. 依次运行：
   - python scripts/gen_consult.py
   - python scripts/append_history.py
   - python scripts/gen_monthly.py
   - python scripts/gen_overseas.py
   - python scripts/gen_weekly.py
2. 运行 `python scripts/validate_info_update.py`，确认历史条目没有减少。
3. 运行 `npm ci` 与 `npm run build`。
4. 提交本次数据变化到 `main`，再将 `dist/` 完整同步到 `gh-pages`。
5. 验证线上 `consult-data.json` 的 `generatedAt` 与本地一致。

当前自动任务仅新增国内官方源资讯；海外历史数据会保留，但不会自动检索或翻译新增海外条目。
任一抓取、校验、构建或部署步骤失败时，停止发布并保留现有线上版本。
